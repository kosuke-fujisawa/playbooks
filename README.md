# playbooks

AIエージェントにURLを渡して使わせるための、プレイブック・仕様書集。

各フォルダに1テーマのプレイブックが入り、フォルダ内の README.md が本文です。使うときは、その README.md のURLをエージェントに渡してください。人間向けの紹介文ではなく、エージェントがそのまま実装に使える粒度で書いてあります。

## 一覧

- [muse-operations](muse-operations/README.md) ― Muse運用プレイブック。個人向けAIエージェント（Muse）に生活の見回りを任せるための仕組みを、目的・構成・ジョブ定義・指示文テンプレート・状態管理・失敗モードまで定義した仕様書。
